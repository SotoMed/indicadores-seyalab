Firebase y usuarios

Esta versión ya usa Firebase Authentication para entrar con correo y contraseña, y Firestore para guardar hojas internas y registros externos. Los usuarios se crean en Firebase Console, no dentro de la página, para no exponer permisos de administrador en el navegador.

1. Crear usuarios

  1. Entra a Firebase Console.
  2. Abre el proyecto seyalab-dashboard-ventas.
  3. Ve a Authentication.
  4. Entra a Users.
  5. Presiona Add user.
  6. Captura correo y contraseña.

2. Reglas de Firestore

  1. Ve a Firestore Database.
  2. Abre la pestaña Rules.
  3. Borra lo anterior.
  4. Pega estas reglas.
  5. Presiona Publish.


3. Verificación rápida

Después de crear usuarios y publicar reglas, vuelve a GitHub Pages, actualiza con Ctrl + F5, inicia sesión y prueba guardar un registro en Externos y facturas. La app usa las colecciones hojas_servicio_seyalab y externos_facturas.
