1. Conectar este tablero con Firebase

Primera vez: crea el proyecto en Firebase, activa Authentication y Firestore, luego pega aquí la configuración firebaseConfig. Esta configuración no es contraseña; los permisos reales se controlan con Authentication y Rules.

2. Iniciar sesión

Los usuarios se crean en Firebase Console → Authentication → Users. Para iniciar, crea uno para administrador y dos para vendedores.

Reglas iniciales de Firestore

Estas reglas son para la primera prueba: cualquier usuario autenticado puede leer y escribir. Después haremos reglas por rol: administrador y vendedor.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /sales_records/{recordId} {
      allow read, create, update, delete: if request.auth != null;
    }
    match /settings/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}
